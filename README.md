# Java VSCode Mini-Project Suite

ElGamal  
--> Simple java code illustrating ElGamal decryption algorithm. Returns a decrypted message given a user-inputted private key and cyphertext.

SuperCrusher  
--> Simple java code implementing Huffman Compression/Encoding. Takes a string from user input and returns the best possible compression ratio.

StringSearch  
--> Simple java code that uses kmp (Knuth-Morris-Pratt) method to search a user-inputted string using a given pattern.
